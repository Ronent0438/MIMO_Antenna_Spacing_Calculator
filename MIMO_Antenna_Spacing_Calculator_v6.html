📖 MIMO Antenna Spacing Calculator — User Guide
🚀 Quick Start
This tool calculates the optimal antenna vertical separation for MIMO operation on a point-to-point microwave link, and shows which modulation orders are achievable given the actual or planned spacing.
In 3 steps:
Step 1
Select your frequency band and channel bandwidth, then enter the link distance — or click two points on the map to set Site A and Site B. The distance fills automatically.
Step 2
The tool instantly shows the optimal antenna separation h_opt and the maximum supported modulation at that spacing. Use the Optimal mode to see ideal results.
Step 3
Switch to Custom spacing to enter your real planned or constrained antenna heights. The α gauge and modulation table update live to show the degradation.
💡 Tip: Use the Preset buttons (11 GHz / 20 km, 18 GHz / 10 km, 7 GHz / 30 km) to instantly load common use cases.
💡 Tip: The α gauge is draggable — slide it to explore how spacing affects modulation without entering numbers.
📡 Link Parameters
Frequency Band
Select the operating frequency from 6 to 26 GHz, or enter a custom value. MIMO is most practical at lower frequencies (6–18 GHz) where the required antenna spacing is mechanically achievable on a single mast.
Channel Bandwidth
Selects the MSE threshold table. Available: 14 / 28 / 40 / 56 / 80 / 112 / 224 MHz. Each bandwidth has slightly different MSE thresholds per modulation — the modulation table updates automatically when changed.
Link Distance
Enter manually in km, or click two points on the map. The map distance updates this field automatically on every marker move.
Antenna Spacing Mode
Optimal
Automatically sets h₁ = h₂ = h_opt. α = 1.0 exactly. Use this to see the theoretical maximum performance of the link.
Custom
Enter h₁ and h₂ independently for each site. Each site has a drag slider (range 0 → 2×h_opt). The spacing guide shows the usable range in metres and live α.
💡 When switching to Custom, h₁ and h₂ are pre-filled with h_opt so you start at α = 1.0 and adjust from there.
📐 MIMO Theory & Formulas
Optimal Antenna Separation
For a 2×2 (or 4×4) MIMO link, the two antennas on each mast must be separated so their signals arrive at the remote end with a 90° phase difference — ensuring orthogonality of the MIMO channels.
h²_opt = D × 150 / f
h_opt = √(D × 150 / f)

D = link distance (km)
f = frequency (GHz)
h_opt = optimal separation (m)
Alpha (α) — Spacing Ratio
α measures how close the actual spacing product h₁×h₂ is to the ideal value h²_opt:
α = (h₁ × h₂) / h²_opt
α = 1.0
Perfect orthogonality. Maximum SNR improvement.
0.3 ≤ α ≤ 1.5
Usable range. Some degradation but MIMO remains viable.
α < 0.3 or > 1.5
MIMO not viable. All modulations marked as not supported.
SNR Improvement
SNRᵢ = 20 × log₁₀(2 × |sin(π × α / 2)|) − 3
At α = 1.0: SNRᵢ ≈ +3 dB. At α = 0.5: SNRᵢ ≈ 0 dB. Below α = 0.5: SNRᵢ goes negative.
MSE Max (with 3 dB safety margin)
MSE_max = −38 − (SNRᵢ − 3 dB)
A 3 dB safety margin is deducted from the SNR improvement before computing the achievable MSE. This gives a conservative modulation ceiling. The maximum supported modulation is the highest order whose BW-specific MSE threshold is ≤ MSE_max.
📊 Reading the Results
Summary Metric Cards
h_opt
The ideal per-mast antenna separation in metres for this frequency and distance.
Alpha (α)
Ratio of actual to optimal spacing. Green = OK, Red = out of range.
SNR Improvement
dB gain from MIMO at the current α. Positive = gain, negative = loss vs single antenna.
MSE achieved
The system's effective MSE floor after applying the MIMO gain and 3 dB margin. Lower (more negative) = better. Compared against the BW-specific threshold table to find max modulation.
Max Modulation
Highest modulation order supportable at current α and channel BW.
Status Banner
✓ Optimal α within 5% of 1.0 — ideal configuration.
⚠ Sub-optimal α in [0.3, 1.5] — usable but degraded.
✗ Not viable α outside [0.3, 1.5] — MIMO inoperable.
α Gauge
The colour-coded bar shows α on a 0–2 scale. The green zone (centre) is the optimal region. You can click or drag the gauge to set α interactively — it back-calculates symmetric h₁ = h₂ and switches to Custom mode automatically.
Spacing Sliders (Custom mode)
Each site has an independent drag slider. The scale is 0 → 2×h_opt, with h_opt marked at the centre. The spacing guide below shows the usable min/max range in metres and the live α value.

⛰️ Terrain Profile & Line of Sight
The terrain profiler fetches SRTM 90m elevation data along the great-circle path between the two sites and plots it as a cross-section with LOS and Fresnel zone analysis.
How it works
Data source
opentopodata.org (SRTM 90m), with fallback to open-elevation.com. 61 samples along the great-circle path.
Auto-trigger
Profile loads automatically when both sites are set, and re-fetches 1 second after any marker move.
LOS line
Blue dashed line from Site A antenna tip (ground + AGL height) to Site B antenna tip.
Fresnel 60%
Green band showing the 60% Fresnel zone clearance envelope. Obstructions inside this zone are highlighted in red.
Antenna Heights AGL
Enter the antenna height above ground level (AGL) for each site. This raises or lowers the LOS endpoints. Changing heights auto-refreshes the profile after a short delay.
▲ Optimise Heights
Automatically calculates the minimum tower heights at each site to achieve 60% Fresnel zone clearance (+ 0.5 m margin) at every point along the path. Results are filled into the AGL inputs and the profile is re-fetched.
LOS Status Badge
✓ Clear LOS No terrain above the LOS path. Shows minimum clearance in metres.
✗ Obstructed One or more points where terrain exceeds the LOS height.
⚠️ SRTM 90m data has limited resolution — suitable for initial planning only. Verify with a professional RF survey for final installation.
📋 Modulation Lookup Table
The table lists all modulation orders from 4KQAM (highest) to BPSK (lowest), with their MSE thresholds and throughput capacity for the selected channel bandwidth. Status is determined by comparing MSE_max against each threshold.
✓ MAX SUPPORTED
The highest modulation achievable at the current α and BW. Highlighted in blue.
✓ Supported
Modulations below the ceiling — always usable, just not peak capacity.
✗ Not supported
Modulations above the ceiling — MSE requirement cannot be met at current spacing.
MIMO Configuration Selector
The 1+0 / 2×2 MIMO / 4×4 MIMO buttons above the table control how capacity values are displayed. The base figures are 1+0 (single carrier). Selecting 2×2 MIMO multiplies all capacity values by 2; selecting 4×4 MIMO multiplies by 4. This reflects the spatial multiplexing gain of each MIMO mode.
1+0
Base single-carrier capacity — no multiplier.
2×2 MIMO
Capacity ×2 — two independent spatial streams.
4×4 MIMO
Capacity ×4 — four independent spatial streams.
Capacity Columns
Each column shows throughput in Mbps for a specific Ethernet frame size (64B, 128B, 256B, 512B, 1024B, 1518B). Values are from Ceragon product data for the selected BW and modulation. Entries shown as N/A indicate that modulation is not supported at that BW/frame size. Values ≥ 1000 Mbps are displayed as Gbps (e.g., 1.27 G).
When α is out of range
If α < 0.25 or α > 1.75, all modulations are marked ✗ Not supported — MIMO cannot operate effectively at that spacing.
Changing Channel BW
Each BW has slightly different MSE thresholds and capacity values. The table and column header update automatically when you change the BW selector. The 224 MHz band has 12 modulation levels (no separate 1KL/1KH split).
💡 The MSE thresholds reflect Ceragon IP-20C / FibeAir® product specifications. MSE_max = −41 − (SNRᵢ − 3 dB), where the −3 dB is a conservative safety margin applied before the lookup.
